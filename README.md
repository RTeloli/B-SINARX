# B-SINARX

[![DOI](https://img.shields.io/badge/MSSP-10.1016%2Fj.ymssp.2026.115084-blue)](https://doi.org/10.1016/j.ymssp.2026.115084)
[![Data](https://img.shields.io/badge/Data-10.5281%2Fzenodo.24143247-blue)](https://doi.org/10.5281/zenodo.24143247)

Code accompanying the article *Interpretable discrepancy learning in dynamical systems using Bayesian SINDy-NARX: The B-SINARX framework* (Mechanical Systems and Signal Processing, 2027). **If you use this code, you must cite this article.** See [Citation](#citation).

MATLAB implementation of **B-SINARX**, a Bayesian sparse identification framework for nonlinear autoregressive models with exogenous inputs (SINDy-type NARX models). The model is built from a library of candidate basis functions, can be combined with a known (baseline) physics model, and is trained with sparse or sparse-Bayesian regression. This gives posterior distributions over the model terms and supports uncertainty-aware closed-loop prediction.

The repository includes two example case studies:

| Script | Case study |
|---|---|
| `example_MainNumericalModel.m` | Simulated Bouc–Wen hysteretic oscillator (data is generated by the code, so nothing needs to be downloaded) |
| `example_MainExperModel.m` | Experimental hysteretic system under chirp excitation (requires the dataset from Zenodo) |

## Requirements

- MATLAB (tested on recent releases). Use of the Signal Processing and Statistics and Machine Learning toolboxes is recommended.
- `Main SINDy/Algorithms/gsm/gsm_v5_1_mex.mexw64` is a precompiled MEX file for **Windows 64-bit** only. On macOS or Linux, the GSM solver falls back to the `.m` implementation or has to be recompiled.

## Getting started

```matlab
% from the repository root
addpath(genpath('./'));
example_MainNumericalModel      % runs out of the box
```

## Experimental data (Zenodo)

The experimental measurements total about 2 GB and are **not stored in this repository**. Download them from Zenodo:

> **DOI:** [10.5281/zenodo.24143247](https://doi.org/10.5281/zenodo.24143247)

Extract the archive so that the measurement folders are placed in:

```
Data/Experimental Data GenData/Data Folder/
├── Chirp/
│   ├── Chirp0to40Hz/     Chirp0p05 … Chirp0p30 /  *.mat
│   ├── Chirp0to110Hz/    Chirp0p05 … Chirp0p30 /  *.mat
│   └── Chirp70to110Hz/   Chirp0p05 … Chirp0p30 /  *.mat
├── Rand/                 Rand0p05 … Rand0p30 / Throughout_Time.mat
├── Sine/                 Sine_05p5Hz, Sine_09p5Hz, Sine_17Hz / Throughout_Time.mat
└── Stepped/              Round1_Stepped0p05_*/ ThroughputData.mat
```

Next, run `example_MainExperModel.m` from the repository root.

## Repository structure

```
├── example_MainNumericalModel.m   Numerical example (Bouc–Wen)
├── example_MainExperModel.m       Experimental example
├── Main SINDy/
│   ├── BSINARX.m                  Main B-SINARX class
│   ├── Algorithms/                Sparse regression solvers (STLS, SR3, Sparse Bayes, GSM, trimmed variants)
│   ├── Libraries/, Library/       Candidate basis-function libraries
│   ├── SINDy Calculations/        Core sparse regression routines
│   └── Utils/                     Closed-loop simulation, metrics, helpers
├── Data/
│   ├── BaselineDiscreteModel.m    Known-physics baseline models
│   ├── getTrainingData3.m         Builds delayed input/output matrices
│   ├── Numerical Data Generation/ Bouc–Wen simulator
│   └── Experimental Data GenData/ Loaders and pre-processing for the experimental data
├── Solver/                        Noise utilities
├── Utility Funcs/                 Plotting and post-processing
└── Results/                       Output folder for figures
```
